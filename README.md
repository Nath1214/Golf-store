# GreenPaw Golf - Luxury Performance Apparel

Welcome to the GreenPaw Golf project. This is a high-end, responsive single-page website built with modern web standards.

## How to Run the Website

There are three easy ways to get this website running on your machine:

### Option 1: The Quickest Way (Local File)
1. Download or clone this repository to your computer.
2. Locate the `index.html` file in the project folder.
3. **Double-click `index.html`** or right-click and select "Open with" followed by your favorite web browser (Chrome, Safari, Edge, etc.).

### Option 2: Using VS Code Live Server (Recommended for Development)
If you are using Visual Studio Code:
1. Open the project folder in VS Code.
2. Install the **Live Server** extension (by Ritwick Dey).
3. Click the **"Go Live"** button in the bottom right corner of the editor.
4. Your browser will automatically open the site at `http://127.0.0.1:5500`.

### Option 3: Using a Simple Python Server
If you have Python installed, you can run a local server from your terminal:
1. Open your terminal or command prompt.
2. Navigate to the project directory.
3. Run the following command:
   ```bash
   python3 -m http.server 8000
   ```
4. Open your browser and go to `http://localhost:8000`.

## Project Structure
- `index.html`: The core structure and content of the website.
- `styles.css`: The "Green & Gold" luxury styling and responsive layouts.
- `script.js`: Interactive features including the shopping cart drawer and smooth animations.

## Key Features
- **Responsive Design**: Looks great on mobile, tablet, and desktop.
- **Interactive Cart**: Add items to your bag and view the subtotal in real-time.
- **Accessibility**: Follows WCAG AA standards for high contrast and screen reader support.
- **Brand Identity**: Optimized for a luxury golf experience.
